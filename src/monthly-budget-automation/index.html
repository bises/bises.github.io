Bank-Grade Security & Plaid Integration

Monthly Budget Automation uses Plaid strictly as an encrypted transmission layer for read-only banking data. We follow rigorous security best practices to guarantee data sovereignty.

Read-Only Transactions The application never requests or possesses permissions to move money, initiate ACH transfers, or modify accounts.
Zero Credential Storage Banking login details (usernames, passwords, 2FA) are submitted directly to Plaid's end-to-end encrypted modal and never touch our code.
No Data Monetization Your financial transactions are never sold, rented, aggregated, or shared with advertisers, data brokers, or third parties.
Local Execution The reconciliation engine runs locally via Python and FastAPI on http://localhost:8000. All outputs reside on your local disk.

How It Works

  1. One-Time Link: Run the local server to authenticate accounts via Plaid Link modal in your local browser.
  2. Token Exchange: The app securely exchanges public tokens for read-only access tokens stored in your local configuration.
  3. Automated Ingestion: The CLI queries Plaid's Transactions sync endpoint to retrieve clean transaction data for the target month.
  4. Family Rules Reconciler: The engine categorizes income, flags nonroutine purchases, excludes transfers, and aggregates store visits.
  5. Report Generation: Output artifacts are compiled: a PowerPoint deck and a structured Markdown ledger synced to Obsidian.
